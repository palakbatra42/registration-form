Overview

The Lead Management System API provides endpoints for managing leads, authentication, lead status, and CRUD operations.

Base URL: https://your-domain.com/api/

Features

  • User authentication using JWT
  • Create leads
  • View leads
  • Update leads
  • Delete leads
  • Manage lead status
  • Protected API endpoints

Authentication

The API uses JSON Web Token (JWT) authentication. A valid access token must be provided when accessing protected endpoints.

Authorization Header

Authorization: Bearer <access_token>
Login first to receive an access token.

Login

POST /api/token/

Authenticates a user and returns JWT access and refresh tokens.

Request

{
                "username": "admin",
                "password": "your_password"
            }

Response

{
            "refresh": "your_refresh_token",
            "access": "your_access_token"
        }

Lead APIs

These endpoints are used to create, read, update and delete leads from the system.

Method Endpoint Description Authentication
GET /api/list/ Get all leads Required
POST /api/list/add/ Create a new lead Required
PUT /api/list/update/<id>/ Update a lead Required
DELETE /api/list/delete/<id>/ Delete a lead Required

List Leads

GET /api/list/

Returns a list of all leads.

Headers

Authorization: Bearer <access_token>

Example Response

        "name": "John Doe",

]

Create Lead

POST /api/list/add/

Creates a new lead in the database.

Headers

Content-Type: application/json
Authorization: Bearer <access_token>

Request Body

{
    "name": "John Doe",
    "email": "john@example.com",
    "phone": "9876543210",
    "source": "Website",
    "status": "New"
}

Success Response

{
    "message": "Lead created successfully",
    "lead": {
        "id": 1,
        "name": "John Doe",
        "email": "john@example.com",
        "phone": "9876543210",
        "source": "Website",
        "status": "New"
    }
}

Update Lead

PUT /api/list/update/<id>/

Updates an existing lead.

Example

PUT /api/list/update/1/

Request Body

{
            "name": "John Smith",
            "email": "johnsmith@example.com",
            "phone": "9876543210",
            "source": "Website",
            "status": "Qualified"
        }

Response

{
        "message": "Lead updated successfully"
    }

Delete Lead

DELETE /api/list/delete/<id>/

Deletes a lead using its ID.

Example

DELETE /api/list/delete/1/

Headers

Authorization: Bearer <access_token>

Response

{
    "message": "Lead deleted successfully"
}

Refresh Access Token

POST /api/token/refresh/

Generates a new access token using a valid refresh token.

Request

{
                "refresh": "your_refresh_token"
            }

Response

{
    "access": "new_access_token"
}

HTTP Response Codes

Status Code Meaning
200 Request successful
201 Resource created successfully
400 Bad request / validation error
401 Authentication required or token invalid
404 Resource not found
500 Internal server error
